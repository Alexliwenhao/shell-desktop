# 功能截图素材（产品视频用）

> 用途：产品视频、动图与文档配图的素材库。
> **编号即使用顺序**：打开应用 → 新建会话 → 接入主机 → 终端作业 → 交给 AI → 计划模式逐步执行 → 浏览文件 → 回看历史 → 配置 → 外观 → 安全删除，便于按序剪辑。
> 图片由 `scripts/capture-feature-screenshots.cjs` 通过 Electron 远程调试（CDP）在真实运行的应用上采集，无后期拼接；分辨率与窗口一致（约 1900×1010，125% 缩放下为窗口像素）。

## 重新采集

```powershell
# 1) 带调试端口启动（无需前台焦点；窗口若被最小化，脚本会先恢复再采集）
& "shell-desktop\node_modules\electron\dist\electron.exe" "shell-desktop\lib\main.js" `
  --remote-debugging-port=9222 `
  --disable-backgrounding-occluded-windows --disable-renderer-backgrounding `
  --disable-background-timer-throttling

# 2) 采集（覆盖同名文件；01–24 全量约 5 分钟）
node scripts/capture-feature-screenshots.cjs

# 只补拍其中几步（步骤号即文件名前缀）
$env:SHELL_DESKTOP_ONLY='11,12,13,14'; node scripts/capture-feature-screenshots.cjs
```

脚本每一步独立容错（失败打印 `SKIPPED` 并继续），启动时自动关闭残留弹窗与历史终端标签，保证画面干净。计划模式一组（`11`–`14`）需要：已连接一台主机、可用的模型网关，以及 `02` 先开一个空白会话——脚本会按此顺序自动执行；其中 `04` 会等待模型提交 `propose_command` 卡片（最长约 2 分钟）。

## 功能说明（按模块，可直接当视频脚本骨架）

### 1. AI Shell：一屏三栏的运维工作台
左侧活动栏切换「会话 / 主机 / 文件」，中央是终端工作台，右侧是 AI 对话。三块区域始终同屏，用户在任何时刻都能看到「AI 在做什么」和「机器真实回显是什么」。

### 2. 远端主机（SSH）
主机列表保存连接信息（地址、用户、端口、密码或私钥）；连接后在中央工作台打开远端终端，同时左栏按主机聚合该机器的终端与会话。文件面板跟随当前连接的主机。

### 3. 终端工作台
多标签、多会话并行；本地 Windows shell 与远端 Linux shell 统一体验。终端是「真终端」——命令、回显、退出码都直接呈现。

### 4. 终端 ↔ AI 协同（本产品的核心差异点）
1. 在终端里跑命令、选中关键输出；
2. 点「引用选中内容」，内容作为引用块进入对话草稿（注明来源主机）；
3. AI 基于真实输出给出结论与下一步，并说明可回滚方式；
4. 普通模式下 AI 直接在你的可见终端里执行（`terminal_run`）；
5. 进入 `/plan` 计划模式后，AI 只能把命令作为**待执行卡片**提交（`propose_command`），由你**点击「执行」**才会进入终端——高风险动作的人机分工。

### 5. 计划模式（Plan）
- 入口：输入框敲 `/plan`（也支持 `/plan off` 退出）；输入行出现 **Plan 标识**；
- 计划模式下 AI 只做只读侦察与规划，要执行的命令逐条提交为「待执行命令」卡片；
- 点卡片上的「执行」后命令输入到当前激活的终端，卡片标记「已发送」，AI 读取回显继续下一步或给结论。

### 6. 文件面板（SFTP）
浏览远端目录、进入子目录、路径直达、新建目录、预览文本文件。**行内不提供删除按钮**：文件删除属于高风险操作，界面不暴露入口以免误触。

### 7. 设置与外观
通用设置包含权限模式、语言、工作区（路径输入 / 原生选择目录 / 切换已有工作区）、外观（浅色 / 深色 / 跟随系统）、字号、对话显示密度；模型设置在「模型」页，可配置 Provider 与自定义网关。

### 8. 安全删除（二次确认）
会话与主机的删除都是行内二次确认：第一次点击按钮变红色 ✓，第二次才真正删除；点击该行任意位置取消。删错的风险在交互层被消掉。

## 建议的 60–90 秒分镜

| 时间 | 素材 | 内容 |
| --- | --- | --- |
| 0–5s | `01` / `02` | 开场：一屏三栏 + 点「新会话」 |
| 5–18s | `03` / `04` / `05` | 添加并连接一台 SSH 主机，进入远端终端 |
| 18–30s | `06` / `07` | 执行命令、选中现场输出 |
| 30–48s | `08` / `09` / `10` | 引用进对话 → AI 给出结论与回滚说明 |
| 48–70s | `11` / `12` / `13` / `14` | `/plan` 进入计划模式 → AI 提交待执行命令卡片 → **点「执行」**，命令在终端回显（人机分工的高光段） |
| 70–78s | `15` / `16` | 浏览远端目录、回看按主机分组的历史会话 |
| 78–84s | `17` / `18` | 工作区与模型配置 |
| 84–90s | `19` – `24` | 深色/浅色切换与二次确认删除收尾（可快剪） |

## 需要手工补拍的镜头（CDP 抓不到原生界面）

- 系统托盘菜单：窗口模式子菜单（兼容/扩展/增强/AI Shell）、切换配置、导出诊断
- 安装包与桌面/开始菜单快捷方式、应用图标（Windows NSIS、macOS DMG）
- 自动更新弹窗与「下载完成」提示
- 安全模式界面与启动恢复窗口（需要构造启动故障）
- 多主机同时连接的会话分组演示（当前环境仅存两台主机）
