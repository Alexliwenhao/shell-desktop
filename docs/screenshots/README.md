# 功能截图素材（产品视频用）

> 用途：产品视频、动图与文档配图的素材库。图片全部由 `scripts/capture-feature-screenshots.cjs` 通过 Electron 远程调试（CDP）在真实运行的应用上采集，无后期拼接。
> 分辨率与窗口一致（约 1554×826），浅色与深色主题各覆盖一部分。

## 重新采集

```powershell
# 1) 带调试端口启动（无需前台焦点，锁屏/远程会话也能采集）
& "shell-desktop\node_modules\electron\dist\electron.exe" "shell-desktop\lib\main.js" `
  --remote-debugging-port=9222 `
  --disable-backgrounding-occluded-windows --disable-renderer-backgrounding --disable-background-timer-throttling

# 2) 采集（覆盖同名文件，约 1 分钟）
node scripts/capture-feature-screenshots.cjs
```

脚本每一步独立容错：某一步失败会打印 `SKIPPED` 并继续；截图直接写入 `docs/screenshots/`。

## 功能说明（按模块，可直接当视频脚本骨架）

### 1. AI Shell：一屏三栏的运维工作台
左侧活动栏切换「会话 / 主机 / 文件」，中央是终端工作台，右侧是 AI 对话。三块区域始终同屏，用户在任何时刻都能看到「AI 在做什么」和「机器真实回显是什么」。

### 2. 远端主机（SSH）
主机列表保存连接信息（地址、用户、端口、密码或私钥）；连接后在中央工作台打开远端终端，同时左栏按主机聚合该机器的终端与会话。文件面板跟随当前连接的主机。

### 3. 终端工作台
多标签、多会话并行；本地 Windows shell 与远端 Linux shell 统一体验。终端是「真终端」——命令、回显、退出码都直接呈现，AI 不会替用户隐藏过程。

### 4. 终端 ↔ AI 协同（本产品的核心差异点）
1. 在终端里跑命令、选中关键输出；
2. 点「引用选中内容」，内容作为引用块进入对话草稿；
3. AI 基于真实输出给出结论与下一步，并说明可回滚方式；
4. 需要执行时，AI 走 `propose_command` 提交待执行命令卡片，由用户点击执行。

### 5. 文件面板（SFTP）
浏览远端目录、进入子目录、路径直达、新建目录、预览文本文件。**行内不提供删除**：文件删除属于高风险操作，界面不暴露入口以免误触。

### 6. 设置与外观
通用设置包含权限模式、语言、工作区（可输入路径 / 原生选择目录 / 切换已有工作区）、外观（浅色 / 深色 / 跟随系统）、字号、对话显示密度；模型设置在「模型」页，可配置 Provider 与自定义网关。

### 7. 安全删除（二次确认）
会话与主机的删除都是行内二次确认：第一次点击按钮变成红色 ✓，第二次才真正删除；点击该行任意位置取消。删错的风险在交互层被消掉。

## 建议的 60–90 秒分镜

| 时间 | 素材 | 内容 |
| --- | --- | --- |
| 0–5s | `01` / `03` | 开场：一屏三栏 + 点「新会话」 |
| 5–15s | `04` / `05` | 添加一台 SSH 主机 |
| 15–30s | `07` / `08` / `06` | 打开终端执行命令、浏览远端目录 |
| 30–50s | `09` / `10` / `11` / `12` | 选中现场输出 → 引用进对话 → AI 给出结论 |
| 50–65s | `13` / `14` | 工作区与模型配置 |
| 65–85s | `15` / `16` / `17` / `18` | 深色/浅色切换，强调深色终端可读 |
| 85–90s | `19` / `20` | 二次确认删除收尾（安全感） |

## 需要手工补拍的镜头（CDP 抓不到原生界面）

- 系统托盘菜单：窗口模式子菜单（兼容/扩展/增强/AI Shell）、切换配置、导出诊断
- 安装包与桌面/开始菜单快捷方式、应用图标（Windows NSIS、macOS DMG）
- 自动更新弹窗与「下载完成」提示
- 安全模式界面与启动恢复窗口（需要构造启动故障）
- plan 模式下的「待执行命令卡片」与点击「执行」（需要模型在 plan 模式调用 `propose_command`）
- 多主机同时连接的会话分组演示（当前环境仅存两台主机）
